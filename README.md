# خطة توريد متطلبات الشبكة

لوحة عربية تفاعلية لعرض خطة العمل ومنهجية التوريد والجدول الزمني للمناقصة. تدعم اتجاه الكتابة من اليمين لليسار، وتنسيق الموبايل والتابلت والكمبيوتر.

## التشغيل

نزّل الملف `index.html` وافتحه في المتصفح. لا يتطلب الموقع تثبيت مكتبات أو تنفيذ عملية بناء. يُحمّل الخط العربي IBM Plex Sans Arabic من Google Fonts عند توفر الإنترنت، ويستخدم خطًا بديلًا عند عدم توفره.

## محتويات اللوحة

- ملخص نطاق التوريد: 23 بندًا ضمن خمس حزم، و30 كم من الكابلات.
- جدول زمني تفاعلي مقترح لمدة 8 أسابيع، مع عرض الأنشطة حسب الأسبوع.
- منهجية العمل ومخرجات كل مرحلة ومسؤوليات الفريق.
- جدول بنود التوريد مع التصفية حسب الحزمة وصفحة المصدر.
- فحوص الجودة، سجل المخاطر، وإيضاحات مطلوبة قبل الشراء.
- وضع فاتح وداكن، وحفظ قائمة الإيضاحات في المتصفح.

## تعديل المحتوى

يحتوي `index.html` على النصوص والتنسيق والبيانات والوظائف. داخل قسم JavaScript:

| المتغير | المحتوى |
| --- | --- |
| `items` | بنود التوريد والكميات والوحدات وصفحات المصدر |
| `acts` | الأنشطة وأسابيع البداية والنهاية والأوزان التخطيطية |
| `ph` | مراحل المنهجية والإجراءات والمخرجات |
| `risks` | المخاطر والاحتمال والأثر والمعالجة والمسؤول |
| `qs` | قائمة الإيضاحات |

راجع البيانات المرتبطة عند تغيير النطاق: أرقام الملخص، تقسيم الكابلات والأجهزة، المعالم الزمنية، والفجوات المحتملة. تغيير عدد أسابيع البرنامج يتطلب تعديل الأعمدة والمنحنى ومؤشر الأسبوع أيضًا.

## أساس الخطة

الكميات مستندة إلى جدول المناقصة المرفق من أربع صفحات. مدة الأسابيع الثمانية والأدوار والأوزان تقديرات تخطيطية تحتاج إلى اعتماد المواصفات ومواعيد الموردين. الخطة تغطي التوريد والفحص والقبول؛ التركيب والأعمال المدنية والتشغيل تحتاج إلى تأكيد تعاقدي وخطة مستقلة. النسب الظاهرة تخطيطية وليست إنجازًا فعليًا.
